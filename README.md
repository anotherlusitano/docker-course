# Docker Containers Exercises

A collection of hands-on Docker exercises, from a first container to multi-container setups and Kubernetes.

Built while following the [Complete Intro to Containers](https://master.dev/courses/complete-intro-containers-v2/) course, as a practical way to learn how to build, optimize, and connect container images, and how to run multi-container setups with Docker Compose and Kubernetes.

## Prerequisites

You need to have installed:

- [Docker](https://www.docker.com/)
- [Docker Compose](https://docs.docker.com/compose/)
- [kubectl](https://kubernetes.io/docs/tasks/tools/)
- [Kompose](https://kompose.io/)

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/anotherlusitano/docker-course.git
   cd docker-course
   ```

2. Open the folder of the exercise you want to run.
3. Follow the instructions in that folder's README.md.
